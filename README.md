# SkillSenseAIBot - AI Career Assistant

SkillSense is an AI-powered platform that helps job seekers analyze and improve their resumes using intelligent evaluation tools and automated career assistance.

## Project Overview
Developed collaboratively as a group project of 5 during my internship, SkillSense is a comprehensive career application featuring smart CV analysis, ATS score checking, AI skill extraction, a role-based mock interview bot, user dashboards, and an automated portfolio generator.

## My Contributions & Role
* Dashboard & UI Development: Built and managed the complete user dashboard (`dashboard.html` / `dashboard.js`) where users can track their progress, view session history, and review skill improvements.
* AI Mock Interview Module: Integrated the interview bot feature within the platform, enabling users to practice role-based technical interviews.
* Database & Authentication: Handled backend database architecture and user management using **Firebase (Auth & Firestore)** for secure logins and historical report tracking.

## Key Features
* Smart CV Analysis: Upload PDF/DOCX files to receive instant AI-driven resume feedback.
* ATS Score Checker: Evaluates resume content to ensure compatibility with Applicant Tracking Systems.
* Skill Extraction: Utilizes Google Gemini AI to extract and evaluate candidate skills.
* AI Mock Interview: Role-based practice interface with integrated real-time evaluation logic.
* Interactive Dashboard: Progress tracking, test history, and improvement analytics (Built by Kaniz).
* Portfolio Generator: Automatically generates a customizable professional portfolio web page.

## Tech Stack
* Frontend: HTML5, CSS3, JavaScript (ES6+)
* Backend & Database: Firebase (Authentication & Firestore NoSQL)
* AI API: Google Gemini API
* Deployment & Hosting: Firebase Hosting / Vercel

## Project Structure
* NewIndex.html - Main landing page and platform portal
* dashboard.html / dashboard.js - User analytics and progress dashboard (Managed by Kaniz)
* interview.html / interview.js - Interactive mock interview bot interface
* firebase.js - Firebase setup and database configuration
* auth.js - Authentication handler and session security
