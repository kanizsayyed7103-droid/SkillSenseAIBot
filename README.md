# SkillSenseAIBot - AI Career Assistant

SkillSense is an AI-powered platform that helps job seekers analyze and improve their resumes.

### ✨ Features
- 📄 **Smart CV Analysis** - Upload PDF/DOCX, get instant AI analysis
- 📊 **ATS Score Checker** - Know if your resume will pass ATS
- 🧠 **Skill Extraction** - Gemini AI extracts & evaluates your skills
- 🎯 **AI Mock Interview** - Role-based interview practice
- 📈 **Dashboard** - Track progress, history, and improvements
- 🌐 **Portfolio Generator** - Auto-generates professional portfolio

### 🛠️ Tech Stack
- Frontend: HTML5, CSS3, JavaScript
- Backend: Firebase (Auth & Firestore)
- AI: Google Gemini API
- Hosting: Firebase / Vercel
