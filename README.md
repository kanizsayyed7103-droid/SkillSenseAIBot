SkillSenseAIBot - AI Career Assistant
SkillSense is an AI-powered platform that helps job seekers analyze and improve their resumes.

Project Overview
Developed collaboratively as a group project of 5 during my internship, SkillSense is an intelligent career assistant platform featuring smart CV analysis, ATS score checking, AI skill extraction, a role-based mock interview bot, user dashboards, and an automated portfolio generator.

My Contributions & Role
Dashboard & UI Development: Built and managed the complete user dashboard (dashboard.html / dashboard.js) where users can track their progress, history, and improvements.

AI Mock Interview Module: Integrated the interview bot feature within the platform, enabling users to practice role-based technical interviews.

Database & Authentication: Handled backend database architecture and user management using Firebase (Auth & Firestore) for secure logins and historical report tracking.

Features
Smart CV Analysis: Upload PDF/DOCX, get instant AI analysis

ATS Score Checker: Know if your resume will pass ATS

Skill Extraction: Gemini AI extracts and evaluates your skills

AI Mock Interview: Role-based interview practice with integrated bot functionality

Dashboard: Track progress, history, and improvements (Built by Kaniz)

Portfolio Generator: Auto-generates professional portfolio

Tech Stack
Frontend: HTML5, CSS3, JavaScript

Backend & Database: Firebase (Auth & Firestore)

AI: Google Gemini API

Hosting: Firebase / Vercel
